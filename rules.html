ME / DO TEXT RP

Server นี้ใช้ระบบ ME / DO เป็นมาตรฐาน

ME
บอกสิ่งที่ตัวละครกำลังทำ
*หยิบบุหรี่ขึ้นมาจุด มือสั่นเล็กน้อย*
DO
บอกสภาพแวดล้อมที่คนอื่นเห็นได้
*มีกลิ่นแอลกอฮอล์โชยออกมา*
กฎหลัก
กฎระดับความหมาย
IC / OC
BASIC
แยกตัวเองออกจากตัวละครให้ชัด อย่าเอาเรื่องนอกเกมมาในเกม
Metagaming (MG)
STRICT
ห้ามใช้ข้อมูลที่ตัวละครไม่ควรรู้ เช่น รู้ตำแหน่งจาก Discord
Powergaming (PG)
STRICT
ห้ามบังคับให้คนอื่น RP ตามที่ตัวเองต้องการฝ่ายเดียว
Deathmatch (DM/VDM)
STRICT
ห้ามโจมตีหรือใช้รถชนโดยไม่มี RP นำมาก่อน
FairRP
BASIC
ต้องให้โอกาสอีกฝ่ายตอบสนองก่อนเสมอ
Combat Log
STRICT
ห้าม Disconnect หนีสถานการณ์ต่อสู้หรือระหว่าง RP
Bug Abuse
STRICT
ห้าม Exploit หรือใช้ประโยชน์จาก Bug ในเกม
Hate Speech
STRICT
ห้ามคุกคาม / Hate Speech ทั้ง IC และ OC
Minor RP
STRICT
ห้าม RP เนื้อหาที่เกี่ยวกับผู้เยาว์ทุกกรณี
CHARACTER KILL (CK)

การสิ้นสุดชีวิตตัวละครถาวร

CK ต้องครบทุกเงื่อนไข — Player ยินยอม / ปลอดหนี้ / มีแรงจูงใจพอ / Admin อนุมัติ

🔫 CK จากการถูกฆ่า
เจ้าของตัวละครยินยอมเอง ไม่บังคับ ตายในเกมปกติไม่นับเป็น CK
💊 CK จากการรักษาพยาบาล
เล่น ME/DO คู่กับหมอ อาการสมเหตุสมผล หมอยืนยัน Player ยินยอม
🌉 CK จากการฆ่าตัวตาย
ต้องมี RP เรื่องราวหนักแน่น Admin ประเมินแรงจูงใจ — ถ้าไม่พอ ไม่อนุมัติ
⚖️ CK จากคำพิพากษาศาล
ผ่านกระบวนการศาลใน RP ครบถ้วน Player ยินยอมก่อนเสมอ
หลัง CK — สร้างตัวละครใหม่ได้ทันที แต่ IC Reset สมบูรณ์ ตัวละครใหม่ไม่รู้จักใครเลย ทรัพย์สินจัดการตามระบบมรดกหรือประมูลตาม RP
