MONTHLY IMPORT
รถนำเข้ารายเดือน
ราคาตามประกาศรายเดือน
  • 3–5 คันต่อเดือน แบ่งเป็น Sport 1 / Classic 1 / Sedan 1-3
  • รถผ่านเงื่อนไข Rockstar ก่อนนำเข้าทุกคัน
  • ซื้อด้วยเงินในเกม หรือเงินจริงก็ได้
  • จำกัดจำนวน ขายแล้วขายเลย ไม่มี Rerun
  • ประกาศใน Discord ก่อนเปิดขายทุกเดือน
  • รถ Donate ไม่ได้เปรียบกว่าคนที่สะสมเงินในเกม
PROPERTY
บ้านและที่อยู่อาศัย
1,500 – 4,500 บาท / 30,000 – 100,000$
  • Player หาบ้านที่ต้องการ Admin ตีราคาทั้งเงินจริงและในเกม
  • ราคาเงินจริงขึ้นกับความสวยของ MLO
  • ราคาในเกมอิงค่าครองชีพของ Server
  • มีค่าดูแลรายเดือน 200 บาท/เดือน
  • ขายต่อ Player ท่านอื่นได้จริง ต้องแจ้ง Admin
  • บ้านถูกยึดได้หากค้างค่าดูแลนานเกิน 2 เดือน
