ทำไมต้อง
NewTemp RP?

01
กฎที่เรียบง่าย ไม่ซับซ้อน
Server ส่วนใหญ่ในไทยมี Rule หนาหลายสิบข้อจนคนใหม่กลัวที่จะเล่น NewTemp RP ใช้เฉพาะกฎ RP รากฐานเท่านั้น ได้แก่ IC/OC, PG, MG, DM, VDM, FairRP ไม่มีข้อบังคับที่ซับซ้อนเกินจริง
02
ระบบ Business เต็มรูปแบบ
เปิดร้านได้จริงใน World มีระบบ Craft / Stock / Bill / Menu / Payroll / จ้างงาน ครบวงจร เชื่อมกับ qbx-manage และระบบธนาคาร Feature ที่ยังไม่มีใครทำในไทยในระดับนี้
03
Parking System แทน Garage แบบเดิม
จอดรถได้ทุกที่บนแผนที่ ระบบบันทึก State รถ (พิกัด / น้ำมัน / สภาพตัวถัง) Loop 15 นาทีลบรถออกจาก Map เพื่อลด Load เรียกกลับสภาพเดิม 90–100%
04
Donate ที่ยุติธรรม — ไม่มีซื้อความได้เปรียบ
ไม่มีการขายสิทธิ์ที่ได้เปรียบในเกม รถนำเข้ารายเดือนจำกัดจำนวน ขายแล้วขายเลย ซื้อได้ทั้งเงินในเกมและเงินจริง รายรับรายจ่ายโปร่งใส ทุกคนตรวจสอบได้
05
ระบบอสังหาริมทรัพย์เต็มรูปแบบ
บ้านซื้อ ขายต่อ และถูกยึดได้จริงผ่านกระบวนการศาลใน RP มีระบบประมูลสาธารณะ บ้านที่ทิ้งร้างถูกรัฐยึดและนำมาประมูลตาม Lore ของเมือง

เริ่มจากคนน้อยแต่มีคุณภาพ ทุกตำแหน่งมีหน้าที่ชัดเจน Scale ขึ้นได้เมื่อ Player เพิ่ม

Owner (จู — Dev + Owner)
└── Co-Owner (เปิดเมื่อพร้อม)
    ├── Head Admin (1 คน)
    │   ├── Admin (2-3 คน)
    │   └── Staff / Moderator (3-5 คน)
    ├── Head Developer (Owner / หรือแยก 1 คน)
    │   └── Developer (1-2 คน)
    ├── Head Designer (1 คน)
    │   └── Designer (1 คน)
    └── Head Whitelist (1 คน)
        └── Whitelist Officer (1-2 คน)
Head Admin
1 คน
  • ดูภาพรวมทีม Staff/Admin ทั้งหมด
  • วางตารางเวร / ตรวจสอบการทำงาน
  • รับเรื่องที่ Staff ส่งขึ้นมา Report ตรงถึง Owner
Admin
2-3 คน
  • จัดการ Report Case / Adminjail / Ban
  • ตั้งค่า Business / บ้าน / รถในเกม
  • บันทึกทุกการกระทำใน TxAdmin + Discord
Staff / Moderator
3-5 คน
  • Online คุม Server ตามเวร
  • Noclip / TP / TPM แก้ปัญหาเบื้องต้น
  • รับ Report เบื้องต้น ส่งต่อ Admin
Head Whitelist
1 คน
  • ตรวจ Whitelist รายวัน 18:00–20:00
  • จัดตารางอบรมสำหรับคนไม่ผ่าน
  • Report สถิติ Whitelist รายสัปดาห์
