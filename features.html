01
ECONOMY SYSTEM

ระบบเศรษฐกิจ

ระบบการเงินที่สมจริง ทุกคนเริ่มต้นเท่ากัน และเติบโตได้จากการเล่น RP

💵
Paycheck System
รับเงินเดือนตาม Job อัตโนมัติ ยิ่งทำงานยิ่งได้มาก
🌾
Farming Jobs
งาน Farming หลากหลายที่ Server ตั้งไว้ให้หาเงินได้ตลอด
🎭
RP Income
ขอทาน ขัดรองเท้า ปล่อยกู้ หรือธุรกิจสีเทา อิสระเต็มที่
🏦
Banking System
Cash / Bank แยกกัน ATM ทั่วเมือง ระบบโอนเงินจริง
📊
Tax System
ภาษีรายได้ / รถ / ธุรกิจ / เมือง เก็บอัตโนมัติจาก Paycheck
COMING SOON
💳
Debt System

02
BUSINESS SYSTEM

ระบบธุรกิจ

Flagship Feature ของ Server ที่ยังไม่มีใครทำในไทยในระดับนี้

🏪
Full Business Management
เปิดร้านได้จริงใน World Admin ตั้งค่าจุดต่างๆ Player บริหารเองทั้งหมด เชื่อมกับ ESX-manage และระบบธนาคาร
FLAGSHIP
📦
Stock System
สั่งสินค้าผ่านระบบหรือไปรับเองที่ Supplier ไม่มีค่าส่งถ้าไปเอง
🍳
Craft System
Craft ไอเทมได้ในร้าน ตั้งค่าความอิ่มอาหาร/เครื่องดื่มได้
🧾
Bill & Menu
ออกบิลลูกค้าได้ มี Menu รายการสินค้าในเกม
👥
Employee System
จ้าง Player เป็นพนักงาน กำหนดตำแหน่ง เงินเดือน และสิทธิ์
03
PROPERTY & VEHICLE

บ้านและยานพาหนะ

ระบบอสังหาริมทรัพย์และยานพาหนะที่สมจริงที่สุด

🏠
Property System
ซื้อ ขายต่อ หรือถูกยึดได้จริงผ่านกระบวนการศาลใน RP
🏛️
Property Auction
บ้านที่ถูกทิ้งร้างหรือค้างภาษีถูกนำมาประมูลสาธารณะใน RP
🚗
Parking System
จอดรถได้ทุกที่ บันทึกพิกัด / น้ำมัน / สภาพตัวถัง ครบทุกอย่าง
🔧
Vehicle State
Loop 15 นาทีลบรถออกจาก Map เรียกกลับมาสภาพเดิม 90-100%
🚀
Monthly Import
รถนำเข้า 3-5 คันต่อเดือน จำกัดจำนวน ขายแล้วขายเลย
📍
Zone Parking
ใช้ ox_lib Zone ป้องกัน Player จอดทับที่กัน
